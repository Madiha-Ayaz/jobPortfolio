## 🎨 Color Scheme

### Form Elements
```
Button:
  Default:   Slate-700 (#3a4a64)
  Hover:     Slate-600 (#4a6a8a)
  Border:    Slate-600

Input Fields:
  Background: Slate-800 (#2a3a52) with 40% opacity
  Border:     Slate-700 with 60% opacity
  Text:       Slate-100 (white)
  Placeholder: Slate-600 (gray)
```

### Contact Cards
```
Email Card:
  Gradient: Slate-700 → Blue-700

Phone Card:
  Gradient: Slate-600 → Slate-700

Location Card:
  Gradient: Blue-600 → Slate-700
```

### 3D Background
```
Sphere 1: #3a4a64 (Professional slate)
Sphere 2: #2a3a52 (Dark blue)
Rings:    #2a3a52 (Dark blue)
Particles: #4a6a8a (Muted blue)
Lights:   #4a6a8a, #3a5a7a, #2a4a6a (Blues)
```

## ✨ Interactive Elements

### Hover Effects
```
Form Fields:
  • Subtle scale increase (1.01x)
  • Background opacity increases

Contact Cards:
  • Lift up animation (-8px)
  • Icon rotates and scales
  • Bottom accent line animates in

Submit Button:
  • Scale increase (1.02x) on hover
  • Smooth shadow increase
  • Border brightens
```

### Focus States
```
Form Fields:
  • Scale to 1.02x
  • Slate-600 ring appears
  • Background opacity increases
  • Border highlights
```

## ⏱️ Interaction Timeline

```
Page Load (0-600ms):
  0ms    → Badge fades in + scales
  100ms  → Heading appears
  200ms  → Subtitle fades in
  300ms  → Left column animates
  400ms  → Right column animates
  500ms  → Bottom CTA appears
  600ms+ → 3D background already animating

User Interaction:
  Hover field   → Scale + glow
  Focus field   → Ring highlight

  Hover button  → Scale effect
  Click submit  → Loading animation
  Success       → Checkmark appears
```
